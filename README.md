# Noble Wave website

Marketing site for [Noble Wave](https://noble-wave.com): home, about, products (with a page
per product), contact, privacy and terms. Built with Angular 22 (standalone components, signals, SSR
prerendering) and Tailwind CSS 4. Every route is prerendered to static HTML, so it can be hosted on
GitHub Pages or any static host.

## Requirements

- Node.js 24.15 or later (Angular 22 requires it)

## Commands

| Command | What it does |
| --- | --- |
| `npm start` | Dev server at http://localhost:4200 |
| `npm test` | Unit tests (Vitest) |
| `npm run build` | Production build into `dist/noble-wave/browser`, plus `404.html` for static hosting |

## Where to change things

| To change | Edit |
| --- | --- |
| Company name, email, phone, address, contact form endpoint | `src/app/core/site.config.ts` |
| Services, process, values, tech stack, mission and vision | `src/app/core/content.config.ts` |
| Products, features, screenshots, store links | `src/app/core/products.config.ts` |
| Colours, fonts, buttons, cards | `src/styles.css` (design tokens at the top) |
| Page copy and layout | `src/app/pages/<page>/` |
| Header and footer | `src/app/layout/` |

### Contact form

The form sends mail through [EmailJS](https://www.emailjs.com) (free tier, no backend). Create an email
service and a template in the EmailJS dashboard, then fill `EMAILJS` in `site.config.ts` with the service ID,
template ID and public key. The template can use these variables: `{{from_name}}`, `{{from_email}}`,
`{{reply_to}}`, `{{phone}}`, `{{service}}`, `{{message}}` and `{{subject}}`. In the dashboard, restrict the
key to the `noble-wave.com` domain. While the values are empty, submitting opens the visitor's email app with
a pre-filled message instead. The form includes validation, a hidden honeypot field for bots, and clear
success and error states.

### SEO

`SeoService` sets the title, description, canonical, Open Graph and Twitter tags and page structured data
(JSON-LD) per route. Link-preview cards live in `public/images/og` and are generated by
`node scripts/make-og.mjs` (needs Chrome). `npm run build` also writes `sitemap.xml` and runs
`scripts/seo-check.mjs`, which fails the build on missing titles, descriptions, canonicals, headings, alt text
or broken structured data.

### Adding a product

Add an entry to `PRODUCTS` in `products.config.ts` and put its images in `public/images/story` (cut-out phone
screens) and `public/images/products` (posters). The product page, listing, footer and sitemap routes follow
from that entry; add the new URL to `public/sitemap.xml` too.

## Project layout

```
src/app/
  core/       site and content config, SEO and contact services
  layout/     site shell: header, footer, skip link
  pages/      one folder per page (lazy loaded)
  shared/ui/  icon, section heading, call-to-action banner, product visuals, screenshot gallery
public/       images, robots.txt, sitemap.xml, CNAME
```

## Notes

- The site is light-only (no dark mode).
- The look is the "ocean" design: teal and navy with a coral accent, Manrope type, rounded cards, a floating
  pill header and a technology marquee. Colours and type live in the tokens at the top of `src/styles.css`.
- The privacy policy and terms are drafts for review and are not legal advice.
- The FAQ answers in `content.config.ts` are placeholders to confirm.
